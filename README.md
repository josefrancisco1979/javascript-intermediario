# 📘 JavaScript Intermediário — Lista de Exercícios

Dez exercícios práticos de lógica de programação em JavaScript, cada um em uma página HTML independente.
Os exercícios trabalham laços de repetição, condicionais, `switch`, funções, validação de entrada e manipulação do DOM.

## 📝 Exercícios

| Nº | Exercício | Conceitos principais |
|---|---|---|
| 1 | Classificação Etária | condicionais |
| 2 | Controle de Estoque | `while`, `switch`, menu de opções |
| 3 | Números Primos | laços aninhados |
| 4 | Números Primos em um Intervalo | laços aninhados, entrada pelo formulário |
| 5 | Simulador de Fila de Atendimento | arrays, estrutura de fila |
| 6 | Pesquisa de Satisfação | laços, contagem de respostas |
| 7 | Cálculo de Média dos Alunos | laços aninhados, validação de notas |
| 8 | Análise de Vendas | arrays, totais e comparações |
| 9 | Verificação de Número na Lista | busca em array |
| 10 | Simulador de Caixa Eletrônico | divisão inteira e resto (cálculo de notas) |

## 🚀 Como rodar

Não precisa instalar nada: basta abrir qualquer arquivo `questaoN.html` no navegador.

## 🛠️ Tecnologias

- HTML5
- JavaScript
